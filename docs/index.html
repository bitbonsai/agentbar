Live AI quota HUD for macOS.

Providers

AgentBar reads usage straight from the CLIs you already have installed. It runs without a proxy or an extra account, and leaves out any tool you don't have.

Antigravity Runs agy /usage in a local PTY for Gemini 4 Neon, Claude Opus 5.5, and Argon.
OpenCode Go Queries opencode api for 5h, weekly, and monthly limits.
Codex Reads the latest rate_limits entry in ~/.codex/sessions.
Claude Code Runs claude /usage for Pro and Max plan windows.

Details

  • Pace markers. The vertical tick on each bar shows how much time is left in the window. If the bar is behind the tick, you are burning faster than a steady pace.
  • Auto-expand. Providers above 50% stay collapsed to a single pill. Anything under 50% expands automatically.
  • SQLite history. Every refresh appends to ~/Library/Application Support/agentbar/history.db so you can query your own usage.
sqlite3 "$HOME/Library/Application Support/agentbar/history.db" \
  "SELECT recorded_at, provider_id, window_id, round(remaining_pct, 1) FROM quota_samples ORDER BY id DESC LIMIT 10;"
